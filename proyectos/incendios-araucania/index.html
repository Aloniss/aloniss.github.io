El tallerThe workshop

El taller teórico-práctico es un libro digital hecho con Quarto para aprender a preprocesar, procesar y analizar datos espaciales con Python, con foco en los incendios forestales. Es parte del proyecto Fondecyt de Iniciación 11231083, y sus autores somos John Gajardo, Alén Miranda, Danko Inzunza y Robert Padilla. Tiene cinco módulos:

The hands-on workshop is a digital book built with Quarto for learning to preprocess, process and analyze spatial data with Python, with a focus on wildfires. It is part of the Fondecyt Initiation project 11231083, and its authors are John Gajardo, Alén Miranda, Danko Inzunza and Robert Padilla. It has five modules:

  1. Introducción a Python y librerías esenciales: Git Bash, Miniconda, ambientes y Spyder.
  2. Introduction to Python and essential libraries: Git Bash, Miniconda, environments and Spyder.
  3. Fundamentos de geomática y visualización de datos ráster.
  4. Geomatics fundamentals and raster data visualization.
  5. Procesamiento de imágenes satelitales para el monitoreo de incendios: NDVI, NBR, dNBR, RdNBR, RBR y BAI, discretización y vectorización.
  6. Satellite image processing for fire monitoring: NDVI, NBR, dNBR, RdNBR, RBR and BAI, classification and vectorization.
  7. Análisis temporal y estadística zonal.
  8. Time series analysis and zonal statistics.
  9. Modelado y predicción del comportamiento de incendios con Random Forest (este ejemplo).
  10. Modeling and predicting fire behavior with Random Forest (this example).

Cómo funciona el modeloHow the model works

  • Datos: puntos de ignición de la temporada 2016–2017 (con nombre, comuna, combustible y causa, en el formato de las estadísticas de CONAF), puntos sin ignición como muestras de control y un ráster de 250 m con cinco variables normalizadas entre 0 y 1: precipitación, distancia a caminos, distancia a zonas urbanas, elevación (DEM) y pendiente.
  • Data: ignition points from the 2016–2017 season (with name, municipality, fuel and cause, in the format of CONAF's fire statistics), non-ignition points as control samples, and a 250 m raster with five predictors normalized between 0 and 1: precipitation, distance to roads, distance to urban areas, elevation (DEM) and slope.
  • Entrenamiento: se extrae el valor de las cinco variables en cada punto, con etiqueta 1 (ignición) o 0 (sin ignición). El 70 % de los puntos entrena un RandomForestRegressor de scikit-learn y el 30 % restante se usa para medir el AUC.
  • Training: the five predictors are extracted at each point, labeled 1 (ignition) or 0 (no ignition). 70% of the points train a scikit-learn RandomForestRegressor, and the remaining 30% are used to measure the AUC.
  • Predicción: el modelo se aplica a cada píxel de la región; como aprendió de etiquetas 0 y 1, su resultado va de 0 a 1 y se lee como probabilidad de ignición.
  • Prediction: the model is applied to every pixel in the region; since it learned from 0/1 labels, its output ranges from 0 to 1 and is read as ignition probability.

  • For this page I re-ran the book's code with a fixed random seed (42) so the result is reproducible, and added the variable importance (scikit-learn's MDI) and the ROC curve.

# Partición de datos
trainX, testX, trainy, testy = train_test_split(X, y, test_size = 0.3, shuffle = True)

# Entrena el modelo con los datos de entrenamiento
modelo_RF = RandomForestRegressor()
modelo_RF.fit(trainX, trainy)

# Obtiene AUC para la estimación del desempeño
predicciones = modelo_RF.predict(X = testX)
metrica = roc_auc_score(testy, predicciones)

# Predice en cada píxel: (bandas, filas, columnas) → (píxeles, bandas)
